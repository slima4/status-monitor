Public components

Each monitor can appear on your public status page as a component. Changes save automatically.

  • Public — show this monitor on the public page (off keeps it and its incidents private).
  • Public name — what visitors see. Leave blank to show the monitor's real name.
  • Group — optional heading that buckets components into sections on the page (e.g. “API”, “Web”). Blank components appear under “Ungrouped”.
  • Reorder — drag the ⠿ handle (or focus it and press ↑/↓) to set the order shown publicly.
